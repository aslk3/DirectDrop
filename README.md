# DirectDrop

Прямая зашифрованная передача файлов между устройствами (Windows 10/11 x64): файлы и папки, drag and drop, докачка, проверка BLAKE3, сжатие. Файлы и их метаданные идут только напрямую, без серверов-посредников.

**Скачать:** [последний релиз](https://github.com/aslk3/DirectDrop/releases/latest) - установщик, portable ZIP, подпись обновления и исходный код.

Встроенное обновление проверяет только релизы этого репозитория и принимает установщик с подписью Ed25519 (файл `.sig`).
